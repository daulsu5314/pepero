✅ 오픈 전 체크리스트

  1. js/config.js 에 SUPABASE_URL / ANON KEY 입력 (상단 빨간 DEMO 배너가 사라졌는지)
  2. schema.sql 실행 완료, admins 에 내 계정 등록
  3. Edge Function draw 배포 + Verify JWT 끔
  4. X 로그인 제공자 설정 + Redirect URL 에 GitHub Pages 주소 등록
  5. 다른 폰/계정으로 테스트 참여 → 결과 확인 → 테스트 기록 삭제
  6. 기프티콘 수량·확률·기간·X 링크 확인 후 [실제 경품 추첨 ON]
